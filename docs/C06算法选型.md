选择条件：适合腰带安装、100 Hz、STM32F103 裸机 C；无需动态内存、RTOS 或训练环境；可解释其时序，并有明确可复用的许可证。以下是本次实际查看的候选，不表示穷尽所有开源实现。

结论：本次未找到可直接采用的完整实现，按本项目设计自行编写 C 模块。仍复用 C04 已移植的 leech001 MPU6050 双轴 Kalman 滤波结果；不重复引入传感器驱动或新的姿态库。没有把候选源码放入 ThirdParty，也不声称算法来自这些项目。

用户随后确认：**先做标定版，实测后定阈值；MPU6050 尚未固定，先在桌面验证。** 因此本轮只实现定长记录、统计和相对测试参考倾角，不启用自动跌倒报警。阶段③入口期限、保持时间、静止判据，以及样本间断处理仍待标定后明确确认。

后续 C06 顺序：桌面六面数据与静止噪声 → 记录安装方向及佩戴直立参考 → 正常动作/受控装置运动记录 → 确认三段条件和时间边界 → 实现状态机与 10 s 撤销交互 → 上板验收。不能把桌面参考当成身体直立，也不能用软件回放代替实际检出率验证。
