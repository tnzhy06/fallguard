项目作为课程展示，不要像商业项目那样严谨，用尽可能简洁的代码实现功能即可。
使用stm32cubemx+vscode插件+cmake开发，使用ai agent辅助开发。
不使用RTOS。
要充分移植 开源项目地址.md 中的几个开源项目
PA0不用。
按键位PC8和PC9，低电平触发。
LED灯为PA8，低电平点亮。
PA9 PA10作为开发调试串口。
oled屏幕SCL和SDA分别使用PB4 PB5。
JQ8900使用一线串口控制，协议见 JQ8900语音模块16p.pdf文档。
ESP01S刷入AT MQTT固件，STM32发送AT指令控制。AT指令见 ESP-AT User Guide.pdf文档。
时间日期每次上电用ESP01S的SNTP同步之后用stm32 RTC，开发板有32.768kHz 晶振
不用做电源设计，本项目只作为测试demo，不是实际产品。
