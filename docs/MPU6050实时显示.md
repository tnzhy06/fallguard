## 接线与配置

| 模块 | STM32 |
|---|---|
| SCL | PB6 / I2C1_SCL |
| SDA | PB7 / I2C1_SDA |
| GND | 共地 |
| VCC | 按模块要求供电，I2C 上拉至 3.3 V |
| AD0 | GND，对应 7 位地址 0x68 |
| INT / XDA / XCL | 本次不接 |

沿用已有 I2C1 400 kHz，不更改引脚或 .ioc。传感器配置为 ±2 g、±250°/s、DLPF_CFG=3、SMPLRT_DIV=9，目标 100 Hz；主循环轮询 DATA_RDY，每个新样本只处理一次，不使用 DMA 或 RTOS。

开机保持设备静止约 3 秒，启动会采集 200 个新样本计算陀螺零偏，完成后开始实时输出。此过程不能自动识别运动，若启动时移动过，应放稳后复位。加速度使用名义 16384 LSB/g，陀螺使用 131 LSB/(°/s)，不套用上游板子的 Z 轴 14418 修正，也不冒充已做六面标定。

## OLED

默认 MPU6050 页，约每 100 ms 刷新。八个数值同屏显示：

```text
MPU6050 LIVE
AX:+0.087  GX:-0.21
AY:-0.010  GY:+0.21
AZ:+1.144  GZ:-1.00
Roll : -0.58 deg
Pitch: -4.54 deg
A:g G:deg/s
FALL:READY DT:10
```

这是格式示例，不是本次硬件测量值。AX/AY/AZ 单位为 g，GX/GY/GZ 单位为 °/s（已减开机零偏），Roll/Pitch 单位为度；底部为当前演示状态与样本间隔；有效样本数 N 继续通过串口输出。

- INIT：等待初始化和首个样本。
- CAL...：正在采集开机陀螺零偏，保持静止。
- LIVE：当前数据有效。
- ERROR：通信、ID 或配置失败，显示 --，不继续把旧读数当实时数据；查看串口具体错误后复位。

Roll 对应上游 KalmanAngleX，使用 atan2(ay, sqrt(ax²+az²))；Pitch 对应 KalmanAngleY，使用 atan2(-ax, az) 并保留跨 ±180° 处理。它们是模块坐标系中的双轴姿态估计，不是安装标定后的身体倾角，也没有航向角。

K1 循环：**MPU6050（默认）→ GPS 信息 → GPS 信号 → 字符演示 → 中文演示 → 图形演示 → MPU6050**。K2 在任意页手动触发或取消报警；消警后扶正才能再次自动触发，不执行六面数据采集。

## 调试串口

USART1：PA9/PA10，115200 8N1。输出类别和周期统一在 [debug_config.h](../BSP/debug_config.h) 配置，默认只开 MPU 数据与错误；详见 [调试输出配置](调试串口输出配置.md)。每约 200 ms 开始输出一组数据，组内三行间隔至少 20 ms，全部来自同一次采样快照；同一个 n 表示同组：

```text
[MPU] n=1234 A mg=87,-10,1144
[MPU] n=1234 G mdps=-213,217,-1004
[MPU] n=1234 Roll=-58 Pitch=-454 cdeg dt=10 max=14
```

| 串口字段 | 换算 |
|---|---|
| A mg | 除以 1000 得到 g，例如 1144 = 1.144 g |
| G mdps | 除以 1000 得到 °/s，例如 -213 = -0.213°/s |
| Roll/Pitch cdeg | 除以 100 得到度，例如 -454 = -4.54° |
| dt / max | 当前/历史最大有效样本间隔，ms |

分成短行并错开发送，避免把八项数值挤成一条长阻塞日志；仍为固定缓冲/整数输出，不启用浮点 printf。GPS 轮询继续执行，GPS 诊断日志默认关闭，开启后在空闲时隙输出。100 Hz 是传感器配置目标，真实有效采样率和间隔须根据 n、时间及 dt/max 上板确认。
