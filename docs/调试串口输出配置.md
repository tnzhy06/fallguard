# 调试串口输出配置

只修改 [BSP/debug_config.h](../BSP/debug_config.h)：输出开关写 1 表示开启，写 0 表示关闭。修改后编译 Debug 并重新烧录 [fallguard.elf](../build/Debug/fallguard.elf) 生效。不是串口运行时命令，不改变波特率、数据单位或 MQTT 协议。

默认输出 MPU6050 三轴加速度、三轴角速度、Roll/Pitch、错误、简短报警和语音事件。GPS、启动提示、普通状态和按键日志默认关闭。关闭日志不停止 MPU6050 采样、GPS 接收解析、OLED 刷新或按键/LED。

| 开关 | 控制内容 | 默认 |
|---|---|---|
| DEBUG_OUTPUT_ENABLE | 所有调试输出总开关，包括错误 | 1 |
| DEBUG_LOG_BOOT | 启动横幅、时钟、接线和启动说明 | 0 |
| DEBUG_LOG_STATUS | MPU 配置/零偏完成、OLED 初始化成功等普通状态 | 0 |
| DEBUG_LOG_KEYS | K1 翻页、K2 测试报警操作提示 | 0 |
| DEBUG_LOG_FALL | 报警、消警与扶正重新待命事件；不控制检测本身 | 1 |
| DEBUG_LOG_JQ | JQ 初始化命令发送、选曲排队、BUSY 变化和停止请求 | 1 |
| DEBUG_LOG_ERRORS | TIM2/TIM3 启动失败、MPU 通信/ID/配置失败、OLED 故障 | 1 |
| DEBUG_LOG_MPU_ACCEL | 三轴加速度 A mg | 1 |
| DEBUG_LOG_MPU_GYRO | 三轴角速度 G mdps | 1 |
| DEBUG_LOG_MPU_ANGLES | Roll/Pitch cdeg、dt/max | 1 |
| DEBUG_LOG_GPS_FIX | fix、是否有历史位置、参与定位卫星数和位置年龄 | 0 |
| DEBUG_LOG_GPS_POSITION | 经纬度整数微度 | 0 |
| DEBUG_LOG_GPS_UTC | GPS UTC 日期时间与有效位 | 0 |
| DEBUG_LOG_GPS_ALTITUDE | 海拔、HDOP 与有效位 | 0 |
| DEBUG_LOG_GPS_STATS | 接收计数、校验/格式/丢字节/UART 错误统计（两行轮询） | 0 |
| DEBUG_LOG_GPS_SIGNAL | 可见卫星、最大 C/N₀、信号档位等 GSV 指标 | 0 |

只看 Roll/Pitch，保留默认的其他分类为 0，将 MPU 三项改为：

```c
#define DEBUG_LOG_MPU_ACCEL       0
#define DEBUG_LOG_MPU_GYRO        0
#define DEBUG_LOG_MPU_ANGLES      1
```

只看 GPS 经纬度：把上面三项都改为 0，再设置：

```c
#define DEBUG_LOG_GPS_POSITION    1
```

此示例仍保留错误提示。完全静默只需：

```c
#define DEBUG_OUTPUT_ENABLE       0
```

频率也在同一文件：

```c
#define DEBUG_MPU_PERIOD_MS       200U
#define DEBUG_GPS_PERIOD_MS       250U
```

MPU 周期是开始一组新快照的最小间隔；启用的三类字段共用同一样本号，行间至少 20 ms。只启用一个字段时不等其他关闭字段。GPS 周期是相邻两条已启用 GPS 诊断行的最小间隔；若只开经纬度，就每个 GPS 输出时隙都输出经纬度，不必等待其他分类空转。MPU 组内输出优先，GPS 在其余时隙输出，实际间隔可能增加。

这是日志周期，不改变传感器 100 Hz 配置、GPS 5 秒过期规则或 OLED 刷新周期。新加调试信息应通过 DEBUG_PRINT(分类开关, 格式串, 参数...) 接入集中开关，不在中断中打印。

本轮验证：固件编译和严格警告检查；默认、仅姿态、仅 GPS UTC、总开关关闭、全部开启五种实际调度器回放。验证了未启用分类不输出、仅一个字段时不空转、同组 MPU 快照一致、静默时无调试输出且 MPU/GPS 轮询继续。硬件串口表现待烧录确认。

C07 接入后，默认、静默、全部开启三种实际调度器回放已补验语音报警状态传递；一线驱动另有[逐边沿协议回放](../tests/jq8900/README.md)。
