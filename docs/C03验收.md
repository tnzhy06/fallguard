# C03 OLED 移植与验收

C02 已由用户确认上板验收通过。本阶段只做 OLED 驱动和显示验收，不提前接入 GPS、IMU、语音或网络。

## 来源与修改文件

按“开源项目地址.md”第一项移植 zeruns/STM32G4-OLED-SSD1306-I2C-HAL，固定提交 4127e9defa9cfde4b82c87c8e3a4165dbfaa776c。不是另选一套驱动。

- BSP/bsp_delay.c/h：TIM2 1 MHz 计数器短微秒延时。
- BSP/bsp_oled.c/h：保留原库所需显存、字模和绘图实现；适配 PB4/PB5 软件 I2C、ACK 与分块刷新。
- ThirdParty/zeruns_oled/：原字库数据、LICENSE、来源及改动记录。
- App/app_ui.c/h：英文/中文/图形三页验收界面和本地测试报警覆盖。
- App/app_main.c：K1 翻页，K2 控制测试报警页和 LED；撤下已验收的 C02 开机灯光预览。
- Core/Src/main.c：仅 USER CODE 块，TIM2 启动成功后才调用 app_init；更新 C03 日志。
- 根 CMakeLists.txt：显式添加本阶段源码和字库目录。

未修改引脚、GPIO 初始化、.ioc、HAL 或用户已有的 STM32 工具包配置。App 不直接操作外设句柄或寄存器，仅使用允许的 HAL_GetTick 与 BSP 接口。

## 接线

| OLED | STM32 |
|---|---|
| VCC | 3.3 V |
| GND | GND |
| SCL | PB4（OLED_SCL） |
| SDA | PB5（OLED_SDA） |

PB4/PB5 已由 CubeMX 配置为开漏，JTAG 已关闭且保留 SWD。必须有到 3.3 V 的外部上拉，先确认模块板是否自带；STM32F1 输出模式设置 GPIO_PULLUP 不能代替外部上拉。使用上游默认 SSD1306、128x64、7 位地址 0x3C。

## 构建与烧录

VS Code 选择 Debug 配置预设，先执行 CMake: Configure，再执行 CMake: Build。构建整个工程，不对头文件或文档使用“编译当前文件”。

本阶段使用与 VS Code 相同的 cube-cmake 构建，未清空 Debug 缓存。固件为 [fallguard.elf](../build/Debug/fallguard.elf)，沿用 C01/C02 的 ST-Link 下载方式。打开 USART1 串口助手 115200、8N1，再复位板子。

预期启动标题：

    === fallguard C03 ===

初始化需要约 100 ms 供电等待，后续配置和屏幕数据在主循环分段发送。收到所有初始化命令的 ACK 后输出：

    [C03] OLED init ACK OK @0x3C

这表示初始化总线应答成功，不等同于显示外观已验收。

## 三页显示与交互

1. 英文页：FALLGUARD C03、SSD1306 / SOFT I2C、递增运行秒数、K1/K2 提示。应检查 8x16 与 6x8 两种 ASCII 字体。
2. 按一次 K1：中文页显示“你好，世界。”，以及 UTF-8 / 16x16。这是上游字库已有的字，不是全中文字库。
3. 再按 K1：图形页显示完整边框、分隔线、空心矩形、圆、实心矩形及动态进度条。检查四边无错位、图形无异常拖影。
4. 再按 K1 回英文页。长按不重复翻页，沿用 C02 消抖。
5. 任意页按 K2：显示反色 TEST ALARM / K2 TO CANCEL 页面，LED 快闪。再按 K2 取消，恢复底层页面，LED 回离线常亮。报警覆盖期间按 K1 不会盖住报警内容，底层页仍按键切换。
6. 连续翻页和切换报警时，RTC/TIM2 每秒日志应继续输出，按键保持响应。

界面是 C03 驱动验收页，正式时间/网络/GPS/位置页面在后续阶段接入，不显示虚假的定位或联网数据。

## 刷新与故障定位

- 每次 BSP_OLED_Poll 最多发送 16 字节显存数据及定位命令；一帧 64 块，不使用整屏阻塞发送，不关全局中断，不用 DMA。
- UI 以 100 ms 为内容更新目标，但只在上一帧传完后重绘，实际帧率受软件 I2C 和其他任务耗时影响。5 µs 高/低延时是定时目标，不代表已测得总线精确为 100 kHz。
- 若输出 OLED bus/ACK failed：检查供电、共地、SCL/SDA、外部上拉、PB4 的 JTAG 释放和模块实际地址；修正接线后复位重测，不直接改引脚或默认尝试另一套控制器。
- 初始化应答成功但不亮、偏移或花屏：先核对模块是否确为 SSD1306 128x64，再测波形和屏幕方向；需确认后才改控制器参数。
- OLED 失败时主循环不反复等待，按键、LED 和串口时钟诊断仍可工作。
- 若后续显示其他汉字为方框问号，应先检查字库是否收录，不把缺字误认为编码或连线故障。
